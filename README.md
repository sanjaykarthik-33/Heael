## Installation

Clone the repository:

```bash
git clone https://github.com/sanjaykarthik-33/Heael.git
```

Go to the project folder:

```bash
cd Heael
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:5173
```

## Build for Production

```bash
npm run build
```
